# 自动下载离线数据库更新

## 已确认需求

- 新增“自动下载数据库更新”开关，默认关闭。
- 使用任何可用网络，包括移动网络。
- 只扩展周期自动检查；手动检查仍展示更新信息并等待确认。

## 实现安排

沿用现有自动检查与唯一下载 WorkManager 任务，不新增调度链路或权限。开关从属于自动检查，沿用通知权限与检查间隔。自动模式成功入队时不再发送要求手动下载的提醒；入队失败回退原有提醒。实际下载失败保留原库，后续周期可再次尝试。

- [x] 在 `OfflineDatabaseUpdateScheduler` 定义默认关闭的偏好与生效判断；`SettingViewModel` 和离线设置页暴露开关与说明。
- [x] 自动检查发现新版本后按设置入队，下载参数记录自动来源，开始执行前复核开关并跳过已安装版本；手动路径不变。
- [x] 被跳过的任务不显示更新成功；删除数据库时先关闭自动下载，避免下一周期立即恢复用户删除的库。
- [x] 更新同步、通知文档与中英文资源，完成构建、Lint、自审及模拟器验证。

关闭开关只阻止尚未开始的自动下载，不中断已开始的下载。自动检查关闭时保留自动下载偏好但不生效。不新增或运行单元测试；设备验证保留现有运行时数据及用户预览记录，不提交或发布。

## 验证结果

Debug 构建、Lint（0 errors、97 warnings、4 hints）和差异检查通过；无独立审查工具，已完成作者自审。模拟器验证默认关闭、依赖自动检查、偏好持久化、手动确认、后台发现旧版本后自动下载并安装、关闭后只提醒，以及关闭前排队的自动下载跳过且不误报成功。测试通过临时修改本地版本及任务调度时间触发真实官方同步链路，结束后恢复原有离线库和更新偏好。Pixel 真机、移动网络实际传输与下载失败故障注入尚未验证。
