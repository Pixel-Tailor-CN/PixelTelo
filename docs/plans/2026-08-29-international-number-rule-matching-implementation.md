# 国际号码规则匹配实施记录

状态：代码已实现；原模拟器完整矩阵未验收通过。2026-11-08 精简历史现场记录，本轮不修改国际号码逻辑。设计依据见[国际号码规则匹配设计](2026-08-29-international-number-rule-matching-design.md)。

## 实施结果

- 使用 `PhoneNumberRuleMatcher` 统一号码规则存储、校验和候选语义。
- 明确的 `+国家码` 与 `00国家码` 互相兼容，不与无国际标记的纯数字格式跨域匹配。
- 名单 DAO 与历史记录中的当前名单状态使用一致的候选规则；旧非法或空规则不得形成全匹配。
- 未命中的明确非中国国际号码直接放行，跳过国内离线库和实时查询。
- 设置中的 Test Intercept 使用真实识别入口及相同联网设置，不再强制联网。
