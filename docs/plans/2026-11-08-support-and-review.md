# 支持开发者与评价入口

## 目标与方案

移植 PixelText 的 `b6585aa` 与 `9ecdfa6`：设置的关于页增加原生赞助页和固定评价入口，首页增加有门槛、可永久关闭的临时卡片。沿用现有 MVVM、Koin、双语资源及整页预见式返回，不引入支付 SDK、评分 SDK或新的解析依赖。

赞助配置固定来自官网 `/support/config.json`，严格检查协议版本、字段类型、渠道和受信任 URL。配置最多 64 KiB，图片最多 4 MiB，渠道独立加载、重试；支持放大、通过 MediaStore 保存图片及打开内置的支付应用。赞助自愿，不提供数字权益，不记录支付结果；只在用户进入赞助页时加载资源。

首页提示从首次前台使用开始计时，满 7 天、3 个活跃日期、5 次有效使用才有资格。连续前台停留 10 秒计一次，两次至少间隔 30 分钟；后台来电和服务不计数。进入首页时冻结资格，权限、默认角色、离线库初始化、列表加载失败或弹层期间隐藏。首次进入可见区域后开始 7 天展示期限，关闭或点击任一入口后永久停止自动提示。存储失败时不提示，不记录已评价或已付款。

使用独立本地偏好保存最少门槛与退出状态，不读取通话内容、不上传，也不进入系统备份、设备迁移或手动备份。评价目标固定为正式包名 `vip.mystery0.pixel.telo`，支持商店协议与网页回退。

## 实施与验证

1. 增加模型、严格配置解析、资源仓库、本地资格策略与仓库；注册 Koin，沿用现有依赖。
2. 增加赞助页、临时卡片和 ViewModel；接入关于页、主页、前台会话记录和现有返回链路。
3. 增加仅两个支付应用的包可见性声明，不新增权限；补充中英文资源、隐私、使用说明及备份排除。
4. 执行 Debug 构建、lint、差异和 XML 检查；在模拟器验证页面、配置失败、卡片门槛与永久退出、预见式返回、深浅色和大字体。验证不付款、不提交评价、不清除用户数据，临时材料保存在仓库外。

不新增或运行单元测试，不自动提交、推送或发布。
