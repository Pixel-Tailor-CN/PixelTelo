# Argon 首页与来电详情扁平化实施计划

> **执行约定**：使用本批次既有 Herdr 执行方式，复用 GPT-6-Luna / high 实施、Gemini 3.8 Flash / high 页面审查，管理员负责代码与最终审查。不启动每任务新角色；项目明确不新增、不维护、不运行单元测试。本轮已实施并完成限定范围审查，复选框仅表示对应工作的实际完成情况，不构成提交授权；缺样本或设备能力未验证项见文末。

**目标**：按用户提供的 Gemini-4 设计，压缩首页视觉噪音，取消详情内冗余折叠与容器，让当前号码的常用动作直接可达。

**架构**：只改现有 Compose 展示与事件接线，沿用 ViewModel / Repository 状态、号码门禁和回调。详情保留单一 ModalBottomSheet，使用自适应快捷栏和扁平内容；不改变数据结构或查询策略。

**技术栈**：Kotlin、Jetpack Compose、Material3 / Monet，复用现有 ExpressiveTheme；无新依赖、权限或数据库迁移。

**设计来源**：本机 `.superpowers/brainstorm/gemini-argon.md`，SHA-256 `ddb47f455522f6236962eb189ecfe583e1e916da8011d69054040c64b1c6e0bd`。原稿受 Git 忽略规则保护，不强制加入版本库；本计划保留可独立阅读的落地决定。管理员与 Gemini 3.8 Flash 已完成源码会审，结论为设计咨询，不是实现验收。

**起始基线**：`71f3590`，上一轮 UI 已单独提交；社区上报业务基线为其父提交 `ec20815`。本计划编写时未开始下一轮产品代码修改。

## 全局约束与设计裁定

- 新方案覆盖上一轮的“记录信息 / 更多操作默认折叠”和“规则纵向设置菜单”方向：两处折叠全部取消，常用操作前置，减少背景卡片与分隔线叠用。
- 默认无联系人、普通号码、标准字号的列表目标为 **2–3 行**；长联系人、双标签、长错误、大字号和窄屏允许增高，不以裁切、隐藏核心含义或缩小触控区换取行数。
- 加黑、加白是两项独立命令。精确、前缀和标签规则可并存，`CurrentListState.BOTH` 必须如实保留；不引入单选、三态开关或自动移除另一名单。
- 本地标签和识别来源标签不得拼接或混淆；去掉冗长字段前缀后仍保留可见来源差别及本地化无障碍描述。显示开关不限制标签管理，空标签不占位。
- 社区历史快照从列表移至详情，但历史状态、`communityBlockApplied` 真实拒接原因及完整备注/耗时不得丢失，不能误写成当前查询或当前名单事实。
- 质量反馈和骚扰上报独立。保留所有资格门禁、提交隐私确认、失败/结果不确定提示、提交中禁重复及终态说明；不补查、不自动加黑、不新增网络调用。
- 详情移除“我的上报”全局入口；首页带 Tooltip 的图标与设置“数据与上报”入口保留，云端列表仍仅进入时加载。
- 联系人保存与记录删除选择**底部直接操作项**，不采用头部垃圾桶方案；删除保留原二次确认。这是布局选型，不改变删除语义。
- 所有动作至少 48dp 触控目标，有明确角色/描述；中英资源齐全，尊重动画关闭、键盘、返回和底部安全区。不新增动画库或改已修复的扫码生命周期。
- 不修改 Provider、Screening、Backend、凭据、持久化、超时和号码判断。仅在真实必要接线时评估扩大允许路径，不搭建额外验证基础设施。
- 本轮不自动提交、推送或发布。保护 `.superpowers` 原稿；实现完成后更新长期 UI 规范，不能提前将计划行为写成现状。

## 审查重点与主要反例

1. 前缀黑名单与精确白名单同时命中：显示实际状态，快捷按钮不暗示互斥或移除规则。
2. 英文、200% 字号、360dp 窄屏与长联系人：操作与号码可读、可滚动，不重现 `maxLines=1` 裁切。
3. 本地“快递”与来源“涉诈”同时存在，或关闭本地展示：区分来源且管理能力不丢失。
4. 无资格、加载中、提交中、已接受、失败与结果待核实：社区区不抢占首屏，也不把失败误判成功或再次可投。
5. 删除标签、删除记录、保存联系人、关闭或更换详情目标：沿用确认与目标隔离，不误写数据、不把迟到结果显示到其他号码。
