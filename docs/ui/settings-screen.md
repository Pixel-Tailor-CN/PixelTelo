# 设置页

设置页首页使用七个分类入口，按 3、2、2 分成三组：来电识别与拦截、在线查询、离线号码库；显示与提醒、记录与备份；权限管理、关于。首页保留应用底部导航。分类详情使用顶部栏标题和返回按钮，隐藏底部导航，并禁用主页横向滑动。返回后恢复首页滚动位置；导航分类与滚动位置支持状态恢复。

## 分类与内容

- **来电识别与拦截**：拦截行为、重复来电、记录与检查。保留仅提示、社区拦截门禁、重复来电策略与时间、记录开关和模拟检查。
- **在线查询**：查询服务和帮助。保留联网开关、Backend、自定义查询源、超时和自建服务文档入口。
- **离线号码库**：号码库和更新检查。保留版本、检查更新、自动检查及间隔。
- **显示与提醒**：显示与反馈、悬浮窗。保留本地标签、通话状态震动、反馈通知及悬浮窗设置和定位调整。
- **记录与备份**：记录、备份与恢复。我的上报、本地标签、备份和恢复仍使用既有页面、文件选择器及隐私范围。
- **权限管理**：显示悬浮窗和应用权限的实时授权状态；首页摘要分别说明必要权限是否齐全，以及可选权限的实际授权数量。授权分类继续使用原系统授权流程。
- **关于**：版本、反馈和外部链接。点击版本仍使用原调试解锁手势；调试模式仅在解锁后显示。

## 首页摘要

首页摘要读取当前设置或运行状态：拦截摘要跟随“仅提示”；在线查询关闭时明确显示仅使用本地号码库，开启时显示当前 Backend 和超时；离线库显示初始化状态或实际版本；显示与提醒摘要反映悬浮窗开关、联网门禁和权限；权限摘要统计当前已授权项目；关于摘要使用实际应用版本和版本号。上报记录、标签与数据备份摘要为固定说明。

在线查询设置中的 Backend 行，以及主页的自建服务入口，都会打开独立的查询服务器管理页并定位到在线查询分类。管理页分别显示官方与自建服务的实际状态、自建配置详情和对应操作；未配置时可直接选择扫码、粘贴或手动配对。配对使用独立的手动、粘贴、扫码和确认页面。手动或粘贴内容有修改时，切换配对方式或离开页面会先确认丢弃；确认页返回到最初的配对方式。页面重建时恢复当前路由和非敏感字段，Token 与原始 JSON 只由页面临时持有。验证成功后回到管理页。查询源继续使用现有弹窗。权限与文件选择 Activity Result launcher 保持在设置页组合中，分类切换不会重建其所有者。

手动和粘贴页的替代入口放在可滚动正文内，底部固定区只保留“下一步”；粘贴操作紧随输入框。确认页以卡片展示地址、证书、Pin 与已填写的令牌状态；扫码无相机或无权限时，在可滚动的预览区域居中显示说明和操作。

## 视觉与行为边界

分类卡片和设置行沿用 `SettingsGroup`、Material 3 色彩角色和系统动态配色。首页横向留白 16dp、三组间距 24dp，组内行间距 2dp；详情组标题与行间距 8dp，详情分组间距 24dp。深色外观跟随系统，不固定亮色背景。

社区标记默认只提示。社区号码拦截只在联网查询开启且使用官方服务时可用，并继续遵循名单规则。离线库自动检查只检查并通知，不自动下载；更新间隔仅在自动检查开启时可编辑。通话状态震动和通话后反馈提醒继续受原权限与 Backend 门禁约束。悬浮窗设置继续受联网门禁约束，参数保留原有保存和预览逻辑。

系统备份和设备迁移不包含通话记录、名单或本地标签。手动 ZIP 备份只包含用户勾选的数据，含社区历史展示快照，不包含上报身份或反馈凭据；恢复只写入用户勾选的范围。
